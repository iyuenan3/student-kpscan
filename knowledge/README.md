# 知识点树（核心资产）

错题识别后归类、知识点薄弱统计都依赖这棵树。它是 student-kpscan 的核心资产，独立于识别代码长期维护。

## 文件

- `zhejiang-math-kp-v0.yaml`：浙江省初中数学知识点树 v0（浙教版，七上至九下全册）。

## 层级与 ID 方案

四级：`册 → 章 → 节 → 点`。

- 册码：`7A 7B 8A 8B 9A 9B` 对应 七上 / 七下 / 八上 / 八下 / 九上 / 九下。
- ID 用点分层：
  - 章 `8A.2`（八上第 2 章）
  - 节 `8A.2.7`（八上第 2 章第 7 节）
  - 点 `8A.2.7.1`（该节第 1 个知识点）

识别归类时，模型只能从本表已有的 `id` 中选，不得自造。统计按 `id` 聚合，所以 **id 要稳定**。

## v0 的来源与边界（重要）

- v0 由大模型按浙教版教材目录生成，**未经浙江中考考纲校准**，章节标题、节次归属可能与最新教材 / 考纲有出入。
- 个别不确定项（科学记数法节次、韦达定理是否列入、梯形是否独立成节、三角形外接圆节次、实数册次）已在 YAML 对应位置用 `# note` 标注，校准时优先核对。
- `考频`、`难度` 字段为迭代 2 预留，v0 不填，避免无依据的假数据。

## 校准规范（考纲电子版到位后）

1. 以浙江中考考纲 + 浙教版最新教材目录为准，修订 `name` 和层级。
2. **尽量保留已有 `id` 稳定**：节点改名直接改 `name`；只有真正删除 / 拆分知识点时才动 `id`，并记录映射，避免历史错题统计错位。
3. 新增知识点：在所属节下追加 `点`，id 顺延（如该节已有 `.1 .2`，新增 `.3`）。
4. 校准完成后把 `meta.version` 升为 `v1`，`status` 改为「已按 XX 考纲校准」，并更新 `generated` 日期。

## 校验

```bash
python spike/recognize.py check --kp-tree knowledge/zhejiang-math-kp-v0.yaml
```

会打印册 / 章 / 节 / 点数量，并检查 id 是否唯一、层级是否自洽。
