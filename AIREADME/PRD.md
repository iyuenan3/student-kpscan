> 本文件 = 本项目产品意图与商业上下文的真相源，内容蒸馏自需求沟通（合作 / 分工 / 学科优先级等）。涉及需求方个人及具体商业数字的部分不入库。

## 目标
初中错题 AI 诊断辅导工具，纯工具型。让一摞错题图自动识别 + 关联中考知识点，定位知识点薄弱处，让刷题有反馈。起步：浙江省中考体系，初中数学先行。

## 用户问题
- 孩子机械抄错题、盲目刷题，错题不知道错在哪个知识点。
- 不知道哪个知识点最薄弱、该往哪使劲。
- 家长 / 老师缺一个低摩擦、本地化的错题诊断工具（市面产品多以卖课为目的）。

## 成功指标
- **spike gating**：印刷体读题准确率 + 知识点归类准确率达通过线。⚑ 通过线待与需求方拍定（建议如读题 ≥95% / 归类 ≥85%）。
- **MVP**：1 周内交付数学诊断报告闭环（Windows），需求方能用自家娃错题卷跑出薄弱点报告。
- 长期：作为需求方副业向其他家长售卖，成本回收 + 客户成功案例。

## UX 哲学
- **低摩擦**：家长批量丢文件夹导入，不强制逐题操作（自动检测放迭代）。
- **纯工具**：只做诊断 + 薄弱定位，不卖课、不塞推荐（推荐放迭代 1）。
- **本地优先**：数据本地存储，保护未成年人隐私。

## 商业 / 合作
- 模式：对需求方按合作折扣价交付；产品跑通后作为需求方副业向其他家长售卖，成本回收 + 持续收入。
- 成本：初期个人 / 小范围承担。
- 合作原则：透明沟通、分阶段投入、风险共担、节点评估（每节点共同评估功能 / 成本 / 下一步）。

## 关键风险
- **识别准确率（crux）**：数学公式 / 几何图识别准确率，spike 验证（头号风险，ADR-004 即为此设 gating）。
- **归类无 ground truth**：知识点归类靠老师经验 + 真题人工核对，准确率天花板隐性。
- **数据依赖需求方**：考纲 / 教辅 / 真题电子版依赖需求方，属关键路径；建议把考纲电子版提为 MVP 前置依赖。
- **输入摩擦**：家长手动裁剪错题，迭代用整页拍 + 点选 / 红叉检测缓解。
- **Windows 部署**：360 误报 + 杀软签名（部署现场坑）。
- **vision 渠道 + key 管理**：newapi 需配 vision 渠道（当前未接，见 RELATIONS）；未来分发时客户端不能 ship 主 key。
- **隐私**：学生试卷图过 newapi → 上游模型（未成年人数据，小范围可接受，规模化前需评估）。
