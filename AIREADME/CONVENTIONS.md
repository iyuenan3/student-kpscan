## 命名
- **知识点 ID**：`册.章.节.点`（如 `8A.2.7.1`）。册码 `7A/7B/8A/8B/9A/9B` = 七上 / 七下 / 八上 / 八下 / 九上 / 九下。ID 分配后**不可变**（见 DECISIONS-006）。
- 知识点树文件：`knowledge/zhejiang-<学科>-kp-<版本>.yaml`。

## 偏好模式
- **配置解析顺序**：CLI flag > 环境变量 > `.env` 文件 > 默认（spike 脚本如此，MVP 沿用）。
- **识别求可复现**：`temperature=0`；报错时**原样打印 newapi 返回体**（渠道没配 / 模型名错 / 余额不足 / 证书问题都看得见）。
- **知识点树校准**：改名在原地改（不动 ID）；结构性大改才 bump 版本（v0 → v1）。
- 图片传输：base64 data URI，`detail=high`（便于读小字 / 公式）。

## 禁用模式
- **中文全角标点**（：（）；），**绝不用破折号**（—— / —）。适用所有产出：文档、commit message、报告。
- **不硬编码 key**；不直连模型厂商（一律经 newapi）。
- **不把样本 / 识别产物入库**（含未成年人试卷及其转写文本）。
- Edit 含中文 / 非 ASCII / 引号变体时，**先 Read 精确 copy-paste**（全角半角易混导致 String not found）。
