## 身份
初中错题 AI 诊断辅导工具，纯工具型（不卖课）。核心闭环：拍错题 → vision 识别 + 关联浙江中考知识点 → 按知识点统计薄弱点 → 诊断报告 →（迭代）推荐专项练习。起步范围：浙江省中考体系，初中数学先行。

需求方：培训行业从业者（3 位）。开发方：项目 + 技术全栈一人。

## 使命 / 解决什么问题
slogan：让孩子没有一道题是白刷的。

解决机械抄错题、盲目刷题：错题不知道错在哪个知识点、哪个知识点最薄弱。用 AI 把一摞错题图自动识别 + 归到中考知识点，定位薄弱处，让刷题有反馈。差异化：区别于猿辅导 / 作业帮以卖课为目的，本产品只做错题诊断 + 知识点薄弱定位。

## Non-Goals（明确不做）
MVP 只做三件：① 只传错题图（家长自己拍 / 裁剪，批量丢文件夹）② 只数学 ③ 只出诊断报告（知识点薄弱点排序 + 错题数 + 可导出）。

明确不做（MVP 范围红线，防膨胀）：
- 不判对错、不检红叉（家长自己挑错题，不做自动检测）。
- 不推荐练习（需题库，放迭代 1）。
- 不做其他学科（科学 / 英语 / 语文，放迭代 2 及以后）。
- 不做移动端、不做中长期学习计划。
- 不卖课、不做家长众筹。

## 绝不 / Hard Constraints（红线）
1. **不提交任何 key / 密钥进 git** — newapi 端点令牌只存 `spike/.env`（已 gitignore），绝不硬编码、不进 git。⚠️ 本文件及任何 AIREADME 文件不写具体 key/secret 本身，只写约束。
2. **识别一律走 newapi 网关的 vision 模型**（OpenAI 兼容端点），不直连厂商、不在客户端硬编码厂商 key。
3. **未成年人数据保护** — 学生试卷图含未成年人数据：不外泄、不留云、规模化前评估隐私；测试样本 / 识别产物不入库（`.gitignore` 已挡 `samples/`、`spike/out/`）。
4. **spike 是硬 gating** — 识别率 spike 未验证通过，不开始 Tauri / MVP 开发。
5. **MVP 范围不扩**（防膨胀）— 不做对错判断 / 红叉检测 / 推荐练习 / 其他学科 / 移动端。
6. **中文全角标点**（：（）；），绝不用破折号（—— / —）。适用所有产出文档 / commit message。
