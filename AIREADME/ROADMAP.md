## Now（当前焦点）
**第 0 步：识别率 spike（硬 gating）。** 工具已就绪并自测通过（知识点树 v0 + `spike/recognize.py`）。

**解禁判定**：以下三条件全满足 → spike 通过 → 解禁进 MVP 开发（阶段 B，照 `ARCHITECTURE` 蓝图 Step 0~8）：
1. **vision 渠道可用**：newapi 网关侧接入 vision chat 渠道（豆包 vision / Qwen-VL）。达成定义 = `recognize.py check` 连通 + 单图 `run` 能出 JSON。
2. **识别率实测**：需求方提供 20~30 张真实错题样本（初一 / 初二数学印刷体，含公式 / 几何，不入库）→ `run --dir` 批量 → 人工填 `review.csv` → `score` 算出读题 / 归类两准确率。
3. **通过线达成**：与需求方拍定阈值（建议读题 ≥95% / 归类 ≥85%），实测达标则解禁；不达标先迭代识别方案（换模型 / 调 prompt）再测，不硬进 MVP。

最省钱顺序：`check`（不调 API）→ `run --image` 单图跑通链路 → `run --dir` 批量 → 人工填 `review.csv` → `score`。
